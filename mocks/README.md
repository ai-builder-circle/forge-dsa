# The Heat 🔥

A monthly timed mock, set by the Smiths to match a real format from the Radar.

**How it runs**
- Time limit and number of problems copy a real format (e.g. 2–3 problems, 90 minutes).
- No internet, no AI, no looking at `cases/`.
- Submit by PR into `mocks/<YYYY-MM>/solutions/<github>/`, then the judge scores you.
- Debrief at the next Anvil: what was the pattern under each disguise?

Each month gets a folder `mocks/YYYY-MM/` containing problems in the same layout as `patterns/`.
